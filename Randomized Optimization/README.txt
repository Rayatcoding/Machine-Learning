Files included:

- test_processed.csv: Preprocessed testing dataset.

Requirements:
- Python 3.x
- Jupyter Notebook
- Required packages: numpy, pandas, matplotlib, mlrose-hiive, scikit-learn

To install the required packages, run:
    pip install numpy pandas matplotlib mlrose-hiive scikit-learn

Instructions:
Place A2_code.ipynb, train_processed.csv, and test_processed.csv in the same directory.
Open the A2_code.ipynb file in Jupyter Notebook and run all cells to execute the experiments and generate the results.
All generated figures and plots will be saved in the same directory.
